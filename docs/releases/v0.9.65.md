# FotoArchief v0.9.65

## Nederlands

### Wijzigingen in deze versie

Deze versie maakt de technische basis van Vistora aantoonbaar, herstelbaar en
meetbaar. De release bevat vier samenhangende verbeterfasen.

- Een machineleesbaar capabilityregister, gegenereerde documentatie,
  releaseassetmanifesten met omvang en SHA-256 en geautomatiseerde
  post-releaseverificatie.
- Een transactionele outbox voor ingestjobs met leases, exponentiële retries,
  dead letters, herstelcommando's, optionele Valkey-dispatch en afzonderlijke
  liveness- en readinesscontroles.
- Back-upmanifest v2 met legacy-ondersteuning, providerneutrale versleutelde
  offsitekopieën, wegwerpbare PostgreSQL-restore-drills, S3-versioneringsbeleid,
  tombstones en opslagmigratiepreflight.
- Versiebeheerde prestatielimieten voor exact 50.000 records, een vaste
  semantische relevantieset, CI-resultaatartifacts en automatische
  toegankelijkheidsregressies op publieke en private routes.
- Een toetsenbordbedienbare publieke IIIF Presentation API 3.0-viewer met
  begrensde zoom, pannen, reset en een veilige fallback naar de bestaande
  preview.

### Operatoracties

1. Maak een onafhankelijke back-up en volg de bestaande upgradeprocedure.
   Behoud database, originelen, volumes, installatieconfiguratie en sleutel.
2. Voeg de nieuwe `.env`-waarden toe wanneer u de standaardwaarden expliciet
   beheert:
   - `OUTBOX_QUEUE_CONNECTION=ingest`
   - `OUTBOX_LEASE_SECONDS=60`
   - `OUTBOX_MAX_ATTEMPTS=8`
   - `OUTBOX_READINESS_MINUTES=10`
   - `BACKUP_OFFSITE_DISK=`
   - `AUTOMATIC_RESTORE_DRILL_ENABLED=false`
   - `AUTOMATIC_RESTORE_DRILL_PARENT=`
   - `STORAGE_TOMBSTONE_RETENTION_DAYS=30`
3. De standaard databasequeue blijft zonder configuratiewijziging werken.
   Gebruik `OUTBOX_QUEUE_CONNECTION=ingest_redis` alleen wanneer de private
   Valkey-service actief en gemonitord is.
4. `BACKUP_OFFSITE_DISK` moet leeg blijven of verwijzen naar een bestaande
   private Laravel-filesystemdisk. Automatische restore-drills blijven
   standaard uit. Providerretentie voor S3-objectversies moet minimaal gelijk
   zijn aan de tombstoneretentie van 30 dagen.
5. `docker-compose.yml` geeft alle acht waarden nu expliciet door aan app,
   worker en scheduler via dezelfde namen en bovengenoemde standaarden.
   Bestaande deployments blijven met de defaults werken; eigen Compose-
   overrides moeten deze mappings handmatig overnemen.
6. Er zijn geen nieuwe poort- of volumemappings en geen verhoogde grootte-,
   rate- of timeoutlimieten. De bestaande performancegrenzen zijn niet
   versoepeld.

### Bewijs en grenzen

De lokale PHP-suite slaagt met 675 tests en 4.783 assertions; 34
omgevingsgebonden tests zijn overgeslagen en niet als geslaagd geteld.
PHPStan, Pint, vertaalcontrole, capabilitydrift, workflowlint en
browser-TypeScriptcontrole slagen. De Chromium-browseracceptatie slaagt met
20 tests, inclusief acht axe-routes en de IIIF-toetsenbordinteracties.

De Linux-CI-servicecontainer is de normatieve omgeving voor de
50.000-recordbenchmark. Automatische axe-controle is geen volledige
WCAG-certificering. De viewer gebruikt een begrensde JPEG-preview en biedt
geen IIIF Image API, tileserver of onbeperkte deep zoom. Er wordt geen live
operatorhostdeployment aangetoond.

## English

### Changes in this version

This version makes Vistora's technical foundation verifiable, recoverable and
measurable. The release contains four connected improvement phases.

- A machine-readable capability registry, generated documentation, release
  asset manifests with size and SHA-256, and automated post-release
  verification.
- A transactional outbox for ingest jobs with leases, exponential retries,
  dead letters, recovery commands, optional Valkey dispatch, and separate
  liveness and readiness checks.
- Backup manifest v2 with legacy support, provider-neutral encrypted offsite
  copies, disposable PostgreSQL restore drills, S3 versioning policy,
  tombstones, and storage migration preflight.
- Versioned performance budgets for exactly 50,000 records, a fixed semantic
  relevance set, CI result artifacts, and automated accessibility regressions
  across public and private routes.
- A keyboard-operable public IIIF Presentation API 3.0 viewer with bounded
  zoom, panning, reset, and a safe fallback to the existing preview.

### Operator actions

1. Make an independent backup and follow the existing upgrade procedure.
   Preserve the database, originals, volumes, installation settings, and key.
2. Add the new `.env` values when you manage defaults explicitly:
   - `OUTBOX_QUEUE_CONNECTION=ingest`
   - `OUTBOX_LEASE_SECONDS=60`
   - `OUTBOX_MAX_ATTEMPTS=8`
   - `OUTBOX_READINESS_MINUTES=10`
   - `BACKUP_OFFSITE_DISK=`
   - `AUTOMATIC_RESTORE_DRILL_ENABLED=false`
   - `AUTOMATIC_RESTORE_DRILL_PARENT=`
   - `STORAGE_TOMBSTONE_RETENTION_DAYS=30`
3. The default database queue continues to work without configuration
   changes. Use `OUTBOX_QUEUE_CONNECTION=ingest_redis` only when the private
   Valkey service is active and monitored.
4. `BACKUP_OFFSITE_DISK` must stay empty or name an existing private Laravel
   filesystem disk. Automatic restore drills remain disabled by default.
   Provider retention for S3 object versions must be at least the 30-day
   tombstone retention.
5. `docker-compose.yml` now passes all eight values explicitly to app, worker,
   and scheduler under the same names and defaults listed above. Existing
   deployments keep working with the defaults; custom Compose overrides must
   copy these mappings manually.
6. There are no new port or volume mappings and no increased size, rate, or
   timeout limits. Existing performance budgets were not relaxed.

### Evidence and limitations

The local PHP suite passes with 675 tests and 4,783 assertions; 34
environment-dependent tests are skipped and not counted as passing. PHPStan,
Pint, translation checks, capability drift, workflow lint, and browser
TypeScript checks pass. Chromium browser acceptance passes 20 tests, including
eight axe routes and the IIIF keyboard interactions.

The Linux CI service container is the normative environment for the
50,000-record benchmark. Automated axe checks are not a complete WCAG
certification. The viewer uses a bounded JPEG preview and does not provide an
IIIF Image API, tile server, or unlimited deep zoom. No live operator-host
deployment is established.
